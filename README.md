# Workflow Hub API

A scalable REST API built with Node.js, Express.js, PostgreSQL, and Prisma.

## Features

- User registration API
- PostgreSQL database integration
- Prisma ORM and migrations
- Modular folder structure with routes, controllers, and config
- Environment variable support
- API testing with Postman

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- Postman
